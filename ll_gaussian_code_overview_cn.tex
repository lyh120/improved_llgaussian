\section{设计边界}

v2 保留 Scaffold-GS 的 anchor、offset、feature 以及 opacity/covariance
MLP，可选保留 feature-bank MLP。所有 appearance 均由
\texttt{ExplicitAppearance} 的显式张量表达，不包含 reflectance decoder、
appearance embedding、controller、residual、noise 或 artifact 网络。
\texttt{MODEL\_FORMAT\_VERSION=2} 是强制断代格式；旧 checkpoint 与 PLY
不会自动回填或猜测字段。

\section{层次化反射率}

每个 anchor 保存底色 logits $B_a\in\mathbb{R}^3$，每个 offset 保存细节
$\Delta_{a,k}\in\mathbb{R}^3$。反射率为
\begin{align}
  \bar{\Delta}_a &= \frac{1}{K}\sum_k \Delta_{a,k},\\
  R_{a,k} &= \sigma(B_a+\Delta_{a,k}-\bar{\Delta}_a).
\end{align}
因此 offset 细节严格零均值，$R$ 自然位于 $[0,1]$，不需要 decoder、
\texttt{tanh} 缩放或经验倍率。

\section{显式光照}

主光照是每个 anchor-offset 的单叶灰度 ASG。方向 $z$ 归一化，切向量
$x$ 经 Gram--Schmidt 正交化，并令 $y=z\times x$：
\begin{align}
  \operatorname{ASG}(v)
  &= \max(v^\top z,0)
     \exp[-\lambda_x(v^\top x)^2-\lambda_y(v^\top y)^2],\\
  L &= a+(1-a)e\operatorname{ASG}(v).
\end{align}
锐度使用 $\operatorname{softplus}(\cdot)+\epsilon$，ambient 与 energy 使用
sigmoid，因此无需额外能量、锐度或各向异性正则。

增强分支由有界 RGB diffuse 与完全独立的单叶加性 RGB SG 构成：
\begin{align}
  \operatorname{SG}(v)&=\exp[\lambda(v^\top z-1)],\\
  D&=\sigma(d_{\mathrm{rgb}}^{\mathrm{raw}}),\\
  S(v)&=\sigma(e_{\mathrm{rgb}}^{\mathrm{raw}})\operatorname{SG}(v),\\
  B_{\mathrm{enh}}&=\operatorname{stopgrad}(R)D,\\
  C_{\mathrm{enh}}&=B_{\mathrm{enh}}+(1-B_{\mathrm{enh}})S(v).
\end{align}
该分支不读取 anchor feature 或主 ASG，且无需输出 clamp 即自然位于
$[0,1]$。初始化把增强 prior 解析分解为不超过 $R$ 的 diffuse 基底和剩余
headroom fill，不再计算病态的增强先验与近零反射率比值。

\section{初始化与生长}

初始化将训练相机中的 anchor-offset 投影到图像，使用 Max-RGB Retinex：
\begin{align}
  L_{\mathrm{obs}} &= \max_c I_c,\\
  R_{\mathrm{obs}} &= I/\max(L_{\mathrm{obs}},\epsilon).
\end{align}
跨视角使用中位数；ambient、energy、axis、tangent 与 sharpness 均来自真实
观测的稳健统计。退化方向通过与 axis 最不平行的坐标轴确定性构造。
投影到同一像素的 anchor-offset 只保留距相机最近者，避免隐藏表面的颜色
污染多视图统计。
未观测位置继承全数据集观测的中位数；若整个点集均不可观测则立即报错。

anchor grow 使用实际贡献 densification voxel 的源 anchor 均值继承完整
appearance；增强 diffuse/energy 在 sigmoid 后的物理域求均值，再映回 raw
参数。方向先半球对齐再归一化，ASG frame 重新正交化。prune 同步裁剪
所有显式张量。

\section{Gaussian 空间组合与梯度隔离}

渲染颜色在 rasterization 前组合：
\begin{align}
  C_{\mathrm{low}} &= R L,\\
  B_{\mathrm{enh}} &= \operatorname{stopgrad}(R)D,\\
  C_{\mathrm{enh}} &=B_{\mathrm{enh}}+(1-B_{\mathrm{enh}})S(v).
\end{align}
增强图的 position、opacity、scale、rotation 与 covariance 全部 detach，
因此增强监督只更新增强 SG。反射率与光照诊断图也使用 detach 后的几何：
反射率重建项只更新 $B/\Delta$，illumination photo 与 edge-aware TV 只更新主 ASG。主图和 depth
仍连接 Scaffold 几何。

\section{训练目标}

warmup 与 main 共用同一目标：
\begin{align}
\mathcal{L}={}&
\mathcal{L}^{\mathrm{low}}_{\mathrm{photo}}
+\lambda_R\mathcal{L}_{R\mathrm{rec}}
  +\lambda_{\mathrm{illum}}(\mathcal{L}_{L\mathrm{photo}}+\mathcal{L}_{\mathrm{edgeTV}})\\
&+\lambda_{\mathrm{enh}}(\mathcal{L}^{\mathrm{enh}}_{\mathrm{photo}}+
\mathcal{L}^{\mathrm{enhL}}_{\mathrm{photo}})
+\lambda_{\mathrm{depth}}\mathcal{L}_{\mathrm{depth}}
+\lambda_{\mathrm{scale}}\mathcal{L}_{\mathrm{scale}}.
\end{align}
warmup 只改变 Scaffold 几何学习率与 densification 窗口。进入 main 前仅清空
区间局部的 offset 梯度累计量；opacity、可见次数、anchor 出生时间与 optimizer
状态保持不变。checkpoint 显式保存 warmup 边界与 transition 状态，恢复时必须
与命令一致。
其中
\[
\mathcal{L}_{\mathrm{photo}}
=(1-\lambda_{\mathrm{dssim}})\mathcal{L}_1
+\lambda_{\mathrm{dssim}}(1-\operatorname{SSIM}).
\]
$\mathcal{L}_{R\mathrm{rec}}$ 使用 $R\operatorname{stopgrad}(L)$ 重建低光输入，
$\mathcal{L}_{L\mathrm{photo}}$ 将主光照锚定到低光输入的 Max-RGB，
$\mathcal{L}_{\mathrm{edgeTV}}$ 使用 Max-RGB 梯度反比权重保护光照边缘，
$\mathcal{L}_{\mathrm{depth}}$ 是有效像素上 inverse-depth 与预计算 disparity
的 Pearson 距离 $(1-\rho)/2$。公开的六个权重为
\texttt{lambda\_dssim=0.2}、\texttt{lambda\_scaling=0.01} 及四个默认
为 1 的结构权重。

\section{固定 prior 与格式}

增强 prior 后端可显式选择 CIDNet 或 StableSR，默认缓存分别位于场景目录内的
\texttt{cidnet\_prior/} 或 \texttt{diffusion\_prior\_<gain>/}；Depth Anything
V2 缓存位于 \texttt{depth\_maps/}。StableSR 的低光输入增益是公开参数，不再
使用由图像均值和隐藏目标亮度推导的倍率。\texttt{train.py} 启动时复用带 v2
manifest 的缓存；目录缺失或为空时调用独立预处理脚本生成一次，训练迭代期间
不执行推理或刷新。两种增强后端都输出同一 \texttt{enhancement\_rgb} 接口，
只通过统一的增强 photo loss 监督独立 RGB SG。增强 prior 使用 PNG，depth prior 使用
float32 disparity \texttt{.npy}；manifest 以 \texttt{image\_name} 为唯一键。
缺失、重复、额外、非有限或尺寸不一致均立即失败。

checkpoint 是带命名字段的 v2 字典，包含 Scaffold 张量、显式 appearance、
optimizer、姿态与 densification 状态。PLY 带强制版本属性和固定单叶布局。
\texttt{save\_mlp\_checkpoints}/\texttt{load\_mlp\_checkpoints} 只处理
opacity、covariance 与可选 feature-bank MLP。

\section{数值常数}

\texttt{NUMERICAL\_EPS} 只用于除零、归一化、有限值保护和正锐度。
Scaffold-GS 的视野扩边、filter footprint、初始 opacity 等基线常数在
\texttt{scene/gaussian\_model\_v2.py} 中具名保存，不与 appearance 或
loss 权重混用。
